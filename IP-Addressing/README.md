# IP Addressing

## What is an IP Address?

An IP (Internet Protocol) address is a logical address assigned to a device on a network. It helps identify devices and enables communication between them.

## Types of IP Addresses

### 1. IPv4
- Uses 32 bits.
- Divided into four octets.
- Written in decimal notation.
- Example: `192.168.1.10`

### 2. IPv6
- Uses 128 bits.
- Written in hexadecimal notation.
- Developed to provide a much larger address space.
- Example: `2001:db8::1`

## Public and Private IP Addresses

- **Public IP:** Used for communication over the public internet.
- **Private IP:** Used within private networks.
