# 🌐 Networking Fundamentals

Welcome to my networking fundamentals repository!

This repository documents my learning journey in computer networking as part of my Cybersecurity Diploma at DUCAT, Pitampura.

I'm using this repository to maintain notes, document concepts and showcase practical networking labs.

## Topics Covered

### 1. Networking Models
- OSI Model
- TCP/IP Model

### 2. IP Addressing
- IPv4 Addressing
- MAC (Media Access Control) Address
- Subnetting
- Route Summarization

### 3. Networking Protocols
- TCP (Transmission Control Protocol)
- UDP (User Datagram Protocol)
- RTP (Real-time Transport Protocol)
- DHCP (Dynamic Host Configuration Protocol)

### 4. Routing
- Static Routing
- Dynamic Routing
- RIP (Routing Information Protocol)
- EIGRP (Enhanced Interior Gateway Routing Protocol)

### 5. Practical Experience
- Cisco Packet Tracer
- Creating network topologies
- Connecting network devices in simulated labs
- Configuring static and dynamic routing
- Practising RIP and EIGRP

## Tools Used
